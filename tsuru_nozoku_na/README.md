# 鶴覗くな

> 「覗いてはいけない」を我慢するミニゲーム

---

## ゲーム概要

日本昔話「鶴の恩返し」をモチーフにした短編ホラーゲーム。

機を織る音が聞こえる部屋の前で、あなたは**覗きたい衝動**と戦う。
覗いてしまえば、鶴は飛び立ってしまう——。

- **ジャンル**: ホラー（ジャンプスケアなし）
- **プレイ時間**: 2〜3分
- **エンディング**: 複数

---

## プレイ方法

| 操作 | 内容 |
|------|------|
| マウス移動 | 視点を動かす |
| クリック | 決定・覗く |
| 我慢 | 何もしない |

ゲームの目的は**「覗かないこと」**です。

## 注意事項

### 動作環境

| 環境 | 対応状況 |
|------|----------|
| PC（Chrome/Firefox/Edge） | **対応** |
| PC（Safari） | 動作するが非推奨 |
| スマートフォン・タブレット | **非対応** |

- WebGL 対応ブラウザが必要です
- 初回ロードに時間がかかる場合があります
- ヘッドホン推奨（音響演出あり）

### コンテンツに関する注意

- ホラー演出を含みます
- ジャンプスケア（急な驚かし）はありません
- 苦手な方はご注意ください
