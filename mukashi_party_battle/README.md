# Mukashi Party Battle

日本の童話キャラクターを同時に操作するアクションゲーム

![Gameplay](assets/gameplay.gif)

## ゲーム概要

桃太郎・金太郎・一寸法師の3人を同時に操作し、鬼を倒すフォーメーション操作型アクションゲームです。

### キャラクター

| キャラ | 役割 | 特徴 |
|--------|------|------|
| 桃太郎 | リーダー | バランス型、前方斬撃攻撃 |
| 金太郎 | タンク | 高HP、周囲攻撃 |
| 一寸法師 | スピード | 高速、突進攻撃 |

## 操作方法

### 移動
- **WASD** または **矢印キー** - パーティ全体を移動

### 攻撃
- **J** - 通常攻撃（全員同時に攻撃）
  - 桃太郎：前方扇形斬撃
  - 金太郎：周囲円形攻撃
  - 一寸法師：前方突進
- **K** - 固有スキル（クールタイム：2秒）
  - 桃太郎：きびだんご（味方全員HP回復）
  - 金太郎：まさかり強撃（広範囲大ダメージ）
  - 一寸法師：打ち出の小槌（連続突進）
- **L** - 合体技「桃金寸 三位一体」（クールタイム：5秒、生存者2人以上必要）

### その他
- **R** - ゲームオーバー/勝利時にリスタート

## プレイ方法

### GitHub Pagesでプレイ

1. このリポジトリをフォーク
2. リポジトリの Settings → Pages を開く
3. Source を `main` ブランチの `/ (root)` に設定
4. 数分後に `https://[username].github.io/mukashi_party_battle/` でプレイ可能

### ローカルでプレイ

```bash
# リポジトリをクローン
git clone https://github.com/[username]/mukashi_party_battle.git
cd mukashi_party_battle

# 任意のHTTPサーバーで起動
python3 -m http.server 8000
# または
npx serve .

# ブラウザで http://localhost:8000 を開く
```
