# Assets

このディレクトリにはゲームで使用する画像・音声ファイルを配置します。

## 予定しているアセット

### キャラクタースプライト
- `momotaro.png` - 桃太郎のスプライトシート
- `kintaro.png` - 金太郎のスプライトシート
- `issunboshi.png` - 一寸法師のスプライトシート

### 敵スプライト
- `oni.png` - 鬼のスプライトシート

### エフェクト
- `slash.png` - 斬撃エフェクト
- `impact.png` - 衝撃エフェクト

### 背景
- `arena.png` - バトルフィールド背景

### 音声（任意）
- `bgm.mp3` - BGM
- `attack.mp3` - 攻撃SE
- `hit.mp3` - ヒットSE

## 現在の状態

現時点ではスプライトは色付き矩形で代用しています。
画像を追加する場合は、`main.js`の`preload`関数でロードし、
キャラクター生成部分を修正してください。
